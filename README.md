# SHIFT｜420 TACTICS

高校・大学の420セーラーが、何度も振れ戻る風の中で「どこで、なぜタック／ジャイブするか」を短いシナリオとリプレイで学ぶWebアプリです。艇団戦術へ進む前に、1艇対1艇で返すポイントとゲイン／ロスを反復します。

## 現在のコース

5つのレッスンを段階的に進めます。

- ラダーラングと相対ゲイン
- 振れをクロスに変えるタック判断
- 振れ戻りと暫定ゲイン
- リード艇のカバーと追走艇のスプリット
- ダウンウインドの逆転とジャイブ判断
- リプレイで実航跡、コーチ例、タックしなかった航跡を比較
- 相対ゲイン、横の距離、タックロスを艇身単位で表示
- 判断の質と、後から分かる結果を分けて説明
- 回答と自信度に応じてヒントと次の推奨課題を変更
- 最高点、試行回数、理解状況を端末内に保存
- 最初にSHIFT LABを置き、上りのタックポイント／下りのジャイブポイントを学習の中心にする
- SHIFT LABで上り／下り、振れ幅、振れ戻り、艇間距離、相手の反応を自由に設定
- 標準海面は、右振れ → 平均通過 → 左振れ → 平均通過を、マークへ着くまで繰り返す
- 風の変化速度を3段階から選び、速い振れと遅い振れで判断時間の違いを比較
- タック／ジャイブを複数回行い、操作なしの航跡とゲイン／ロスを比較
- 固定秒数では止めず、マーク到達またはマークを外して通過するまで航跡を再生
- ライブ進行速度を1／2／4倍から選択し、リプレイは再生・停止・1秒送り・速度変更に対応
- 実行したすべてのタック／ジャイブをPOINT 01、02…として残し、各操作だけを前後4秒にずらした仮想試走と比較する
- 同じ風・相手・初期位置で操作列を反実仮想探索し、「マーク到達＋相手より前」になる勝ち筋、または探索内で最も改善した次走案をリプレイに示す
- 各ポイントで、風向、風の動く向き、操作前後のタック、前回操作からの秒数、マーク結果、他艇との差を確認する
- 上りの連続ヘダー、下りのジャイブ窓、1回の振れ戻り、パーシステントシフトをすぐ試せる4つの420向けドリル
- 走る前に最初のタック／ジャイブ時刻を決め、リプレイで `PLAN → DO → REVIEW` を比較
- 海面設定を共有URLに保存し、登録なしでコーチやチームメイトへ配布
- 相手設定の「最適化」は、4°以上の振れ、操作回復、レイライン、12秒先のミートを毎秒読み、教育モデル内で有利なタック／ジャイブへ返す
- 相手艇は12秒先のミートを予測し、上りはタック回復4秒、下りはジャイブ回復3秒に安全1秒を加えた余地があればミート前に操作する。間に合わない近距離だけベアして後ろを通り、ミートがなければレイラインで返す
- リプレイの「MEET CHECK」で、相手が見たミートまでの秒数、予測すれ違い距離、安全余裕を確認する
- RACE LABは、初級4艇のコーチ付き練習と、中級8艇の実戦設定を選べる
- 初級では残り30秒、スタート後の乱れた風、マーク5艇身前で自動停止し、見る順番を声に出す
- 中級では海面、スタート位置、最初に使う海面を自分で決め、複数情報を統合する
- 予告・準備・1分・スタートの信号、個別リコールのX旗、ライン下へ戻る再スタート、スタートラインの有利側を同じ時間軸で読む
- 潮流、風圧帯、振れ戻り、ダーティーエア、レイライン、3艇身ゾーンを見ながら、スタート位置と最初の上り戦略を選ぶ
- リプレイでスタート順位からマーク順位までの増減、クリーンエア率、リフト側を走れた割合、RRS 10／18に関わる注意場面を確認する
- 数値を見る前に自分の改善点を選び、記録との一致／見落としと、次の1走で行うことを確認する
- 「艇長は風圧帯のどちら側か」「クルーへ何と伝えるか」まで、海上で使う短い言葉に直して振り返る

## 学習設計

画面は「風の動きを見る → 今の走りがリフト／ヘダーか言う → 待つ／返す → 全ポイントをリプレイする → 理由を言葉にする」の順で進みます。

専門用語を先に暗記させず、「横に離れているほど風の振れによる差が大きくなる」と説明してから、レバレッジという言葉を結びつける方針です。リプレイでは、現在の風向に直交するラダーラングで艇間の相対ゲインを計算します。

競合サービス、World Sailingのコーチ資料、420向け公式教材、学習科学を比較した実装判断は [Web調査メモ](docs/WEB_RESEARCH_2026-08-23.md) に記録しています。

初学者〜中級者への有用性、足場かけ、形成的フィードバック、実戦転移、スマホ、アクセシビリティの評価は [学習監査](docs/LEARNING_AUDIT_2026-08-23.md) に記録しています。

## デザイン方針

- セールクロス、耐水マーカー、コーチのテープ、海図をモチーフにする
- 装飾用のグラデーション、ガラス調パネル、意味のないカード列を使わない
- スマートフォンで親指操作できる大きさを確保する
- レッスンとSHIFT LABは比較相手を1艇に絞り、RACE LABは初級4艇／中級8艇で情報量を段階化する
- 色だけに頼らず、線種、ラベル、文章でも区別する
- `prefers-reduced-motion` とキーボードフォーカスを尊重する

## シミュレーションの前提

戦術判断を短く反復できるよう、モードごとに次の条件を単純化しています。

- 2艇の基準艇速は同じ
- 風は海面全体で同時に変わる
- レッスンとSHIFT LABは、波、潮、ダーティーエア、航路権を計算しない
- 1艇身は420の全長4.2mとして表示する
- タック時の減速と4秒間の回復を教育用モデルとして設定する
- レッスン2は判断区間の後、教育用の最終レグ制御で風上マークまで航跡を延長する
- SHIFT LABは自艇の操作でマークを狙い、到達とマーク外通過を分けて記録する
- SHIFT LABでは、ポート艇は12秒先までのミートを予測し、上りは4秒のタック回復、下りは3秒のジャイブ回復と1秒の安全余裕があれば早めに操作する。安全余地がない場合だけ「3秒間ベアして後ろを通る」教育用判断に単純化する
- RACE LABはスタート60秒前から第1上マークまでを対象にし、初級4艇／中級8艇、潮流、風圧帯、ダーティーエア、スタートライン、個別リコール、レイライン、3艇身ゾーンを教育用モデルで再現する
- RACE LABの規則表示はRRS 26、29.1、10、18を学ぶための注意喚起であり、抗議審問や公式判定を再現しない
- オリンピック・トラペゾイドの下りとフィニッシュ、波、艇ごとの420ポーラ、クルーワークの失敗、他艇との接触はまだモデル化しない

数値は公式ポーラではなく `420教育用モデル v0.4` です。回復時間、潮流、風圧帯、ダーティーエアの影響量も教育用の暫定値であり、今後、実艇データやコーチの知見で調整します。信号と規則の根拠は [Web調査メモ](docs/WEB_RESEARCH_2026-08-23.md) に記録しています。
