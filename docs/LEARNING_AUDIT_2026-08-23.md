# SHIFT｜初学者〜中級者向け学習監査

監査日: 2026-08-23
追補監査日: 2026-08-24

## 結論

現在のSHIFTは、初学者が戦術用語と因果をつかみ、中級者が複数情報をつないで判断するための教材として、設計上は有用性が高い。ただし、実艇での技能向上はまだ学習者テストと遅延テストで実証していない。

改善前の最大の問題は、RACE LABが8艇、潮、ブロー、ライン、規則を最初から同時に提示し、初学者へ過剰な認知負荷を与えていたことだった。また、リプレイは結果を示しても、学習者自身の見立てと次の練習を結ぶループが弱かった。

今回、初級4艇のコーチ付き練習と中級8艇の実戦設定を分け、`予想・コール → 操作 → リプレイ前の自己評価 → 記録との照合 → 次の1走` を一続きにした。

追補では、さらに学習の主軸をSHIFT LABへ絞った。標準海面は1回の振れ戻りではなく、右・左・右へ何度も動く。ライブ中に「風の動き・今のタックの有利不利・次のコール」をつなぎ、終了後は実行した全タック／ジャイブを個別に前後4秒で比較する。RACE LABは、この判断を艇団へ転移する応用に位置づけた。

その後、SHIFT LABの直近8試行を端末内だけに記録するようにした。操作なし、根拠の未記録、根拠の見直し、マーク未到達を分け、それぞれに同条件の再試行を返す。同じ条件で根拠とマーク到達を2回続けて確認できた場合だけ、風の変化を変えて応用する。

## 対象別の到達目標

### 初学者

- 風向の値と、風が今どちらへ動いているかを区別できる
- 上りで今のタックがリフト側かヘダー側かを言い、ヘダーを返す理由を説明できる
- 下りでは有利なサイドが上りと反対になることを使って、ジャイブ判断を説明できる
- リプレイで自分の各操作を4秒前後と比べ、次の1点を言える
- 残り30秒にラインまでの艇身数と潮を確認できる
- スタート後にクリーンエアか乱れた風かを区別できる
- マーク5艇身前に内外、オーバーラップ、次のレグをコールできる
- 結果を見て、次の1走で直す行動を1つ説明できる

### 中級者

- 連続する振れの中で、操作ロスを払って返す振れと、維持する小さな振れを区別できる
- 2回以上のタック／ジャイブについて、風の動き、他艇との差、マーク結果を使って説明できる
- 潮、ブロー、スタート位置、第1レグの狙いをつないで事前計画を立てられる
- クリーンエア、リフト側、規則リスク、相対順位からゲイン／ロスの主因を説明できる
- 自分の見立てとリプレイ記録のずれを発見し、次の試行条件を変えられる

## 多面的評価

| 観点 | 現状 | 根拠 | 残る課題 |
| --- | --- | --- | --- |
| 学習目標との整合 | 強い | 5レッスン、SHIFT LAB、RACE LABが、概念理解から反復判断、艇団への転移へ進む | 各レッスンの問題数が少なく、遅延後の再確認がない |
| 初学者の足場かけ | 改善後は強い | 4艇、基本海面、3つの見る順番、用語集、判断点での停止を用意 | 実際の初学者が説明なしで開始できるかは未検証 |
| 中級者への挑戦 | 中〜強 | 8艇、3海面、スタート位置、第1レグ計画、規則リスクを統合する | 波、艇速差、クルーワーク、全コースは未モデル化 |
| 形成的フィードバック | 強い | 自己評価を先に取り、OCS、規則、風、シフトの記録から次の1走を返す | 判定閾値は教育用暫定値で、コーチによる校正が必要 |
| 実戦への転移 | 中〜強 | 水上で使う短いコール、Plan–Do–Review、同条件の再確認後に風の変化を変える応用、スタートからMark 1までの連続判断 | 実艇ログとの比較、部活動内の対話、保持テストが未実施 |
| 戦術・規則の妥当性 | 中 | RRS 2025–2028の信号、個別リコール、Rule 10、3艇身ゾーンを参照 | Rule 18の権利や抗議判定は再現せず、SIの違いも残る |
| スマホ操作・可読性 | 強い | 320pxと390pxで横あふれなし、操作ボタンを大きくし、色以外のラベルも使用 | 屋外の日光下、濡れた手、実機Safari／Androidの検証が必要 |
| アクセシビリティ | 中〜強 | 見出し、fieldset、aria-live、フォーカス、reduced motion、停止操作を備える | スクリーンリーダー実機と弱視者による確認が必要 |
| 継続動機・自己調整 | 中〜強 | 端末内進捗、直近8試行の比較、記録に応じた次条件、自己評価と見落とし表示がある | 長期目標、チーム比較、2週間後の再訪設計は未完成 |
| デザインの信頼感 | 強い | コーチ用耐水シート、RC信号板、海図の意匠を一貫して使用 | 420部員が「自分たちの道具」と感じるか定性調査が必要 |

### 追補評価：タック／ジャイブポイントへの焦点化

| 観点 | 改善後の設計 | 残る検証 |
| --- | --- | --- |
| 課題の焦点 | ホーム最上段をSHIFT LABにし、RACE LABは「艇団で使う」応用へ下げた | 初見の高校生が30秒以内に練習目的を言えるか |
| 実海面らしい反復 | 標準条件で右・左・右のシフトをマーク到達まで反復する | 振れ周期と角度は教育用で、実艇ログによる校正が必要 |
| 判断過程 | ライブで `WIND MOVE → NOW → CALL` を示し、操作前に「風・相手・マーク」の優先理由を選ぶ | 理由選択が実艇のクルーコールへ転移するかは対象者テストが必要 |
| 操作点の診断 | 全操作をPOINT LOGにし、それぞれを前後4秒の試走と比較する | 4秒刻み以外の最適点は示さない。BESTは3試走内に限定する |
| 認知負荷 | 初学者は風・今のタック・次の操作の3段に絞る | 同時に相手艇を見る段階への移行条件が未検証 |
| スマホ | 横長のグラフを簡略化し、操作ログは縦方向へ積む | 屋外の実機と濡れた手での操作は未検証 |

## 今回の改善

1. RACE LABの入口に初級／中級を置き、初級は4艇、中級は8艇にした。
2. 初級はライン、走れる風、マーク前の相手関係へ注意を絞った。
3. 残り30秒、スタート後の乱れた風、マーク5艇身前で確実に自動停止するようにした。OCS時はスタートでも止まる。
4. 用語を画面内で確認できるようにし、`ベア` には `下る` を併記した。
5. リプレイの数値より先に「自分では次にどこを直すか」を選ばせた。
6. レース記録から最優先の次課題を1つ返し、同じ海面ですぐ再挑戦できるようにした。
7. 停止点と次課題判定を純粋関数に分け、単体テストを追加した。
8. 標準シフトを反復波形へ変更し、最大振れと平均通過をリプレイイベントに残した。
9. すべてのタック／ジャイブ点を個別評価する純粋関数と単体テストを追加した。
10. 上りと下りで有利なタックが逆になる判定を分離し、ライブ表示とPOINT LOGで共用した。
11. タック／ジャイブ直前に時計を止め、「風・相手・マーク」の最優先理由をコールしてから同じ秒で操作するようにした。
12. POINT LOGで宣言した理由と3つの観察記録を照合し、結果の良否と判断根拠の妥当性を分けた。
13. SHIFT LABの直近8試行を端末内だけに保存し、根拠が確認できた操作数とマーク結果を直近3回で比較できるようにした。
14. 操作なし、根拠の見直し、マーク未到達、同条件での再現、別の風への応用を分け、リプレイ結果が次の練習条件を実際に変えるようにした。

## 評価の根拠と限界

設計判断は、[CAST UDL Guidelines 3.0](https://udlguidelines.cast.org/)、[World Sailing Level 1 Coach Syllabus](https://www.sailing.org/tools/documents/ISAFLevel1TechnicalCourse324.05.13-%5B15060%5D.pdf)、[International 420 Classの公式オンライン教材紹介](https://www.sailing.org/2015/05/05/international-420-class-launches-new-online-training-resource/)、[World Sailingのオシレーティングシフト事例](https://www.sailing.org/2010/01/19/picture-perfect-start-to-key-west-2010/)、[420公式トレーニング動画紹介](https://www.sailing.org/2011/06/02/420-class-launches-online-training-video/)、[Butler & Winneの自己調整学習とフィードバック](https://doi.org/10.3102/00346543065003245)を参照した。

この監査は、公開資料、コード、単体テスト、ブラウザ操作の評価である。「初学者〜中級者に役立つ」という最終判断には、対象者によるユーザビリティテスト、説明課題の事前／事後比較、1〜2週間後の遅延テストが必要である。

## 次の検証プロトコル

- 初学者6〜8名、中級者6〜8名に、説明なしで初級／中級を1走ずつ実施してもらう
- 操作ログに加え、「なぜその操作をしたか」を30秒で口頭説明してもらう
- 直後と1〜2週間後に、新しい風の振れ・艇団配置で同型課題を行う
- 主指標を、開始完了率、誤り後の再挑戦率、判断理由の正確さ、遅延後の転移成功率とする
- コーチには、フィードバックの優先順位と数値閾値が実艇感覚に合うかを評価してもらう
