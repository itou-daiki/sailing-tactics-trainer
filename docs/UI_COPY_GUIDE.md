# UI文言の方針

SHIFTの画面では、雰囲気を優先した比喩や抽象表現を使わず、ユーザーが次の操作を一読で理解できる日本語を使う。

## 基本ルール

- ボタンは、押した後に起きることを動詞で示す。
- 見出しは、その区画で設定・操作・確認する内容を示す。
- 「探しに出る」「判断窓をつくる」「差が動く」のように、意味を考えないと操作が分からない表現は使わない。
- セーリング用語は、420選手が水上で使う語に限る。初学者向けには近くに説明を置く。
- 英語のラベルは補助情報とし、日本語だけでも意味が通るようにする。
- シミュレーション結果は「唯一の正解」「勝ち筋」と断定せず、教材モデル内の比較であることを明記する。

## ボタンの例

| 避ける表現 | 使用する表現 |
| --- | --- |
| 判断点を探しに出る | この条件でシミュレーションを始める |
| 艇団で試す | RACE LABを始める |
| おすすめへ進む | おすすめのレッスンを始める |

## 見出しの例

| 避ける表現 | 使用する表現 |
| --- | --- |
| 判断窓をつくる | 練習条件を設定 |
| 差が動く理由を探す | 自艇と相手艇の差を確認する |
| 何が順位を動かした？ | 順位が変わった理由を確認する |
